# Excel Average Processor

Vue 3 приложение: загружает Excel-файл в браузере и строит таблицу
средних значений — порт VBA-макроса `CreateDynamicAverageTable` на JS.
Сервер не используется.

## Требования к входному файлу

На первом листе должны быть столбцы:

| Столбец | Содержимое                      |
| ------: | ------------------------------- |
|       F | Имя студента                    |
|       H | Числовое значение               |
|       I | Тип (учитывается первый символ) |

Результат пишется в столбцы **K** и далее: строка 1 — заголовки
(`Student`, затем все уникальные типы), далее по одной строке на студента
со средними значениями.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Открой <http://localhost:5173>

## Сборка

```bash
npm run build
npm run preview
```

## Ограничения

- Файлы `.xlsm` при пересохранении теряют VBA-проект (SheetJS).
- VBA `Round` — банковское округление, реализовано через `vbaRound()`.
